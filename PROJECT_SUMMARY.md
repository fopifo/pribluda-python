# Приблуда на Python — краткое описание проекта

## Цель
Скринер торговых роботов (алгоритмов) на MOEX по ленте сделок Алор.
Помощь трейдеру-скальперу в обнаружении работающих алгоритмов в реальном времени и на истории.

## Режимы
- Исторический: скачивание ленты через fetch_history.py, прогон run_detectors.py --all-days.
- Живой: live_screener.py (WebSocket) + GUI + Telegram-меню (start_all.py).

## Детекторы
- fast_strict: стабильный интервал, одинаковый объём (допуск 2 лота), строгие пороги.
- twap_strict: стабильный интервал, объём игнорируется (ignore_qty=True), жёсткий interval_tolerance=0.03.

## Новые возможности (по сравнению со старой версией)
- Джиттер и CV% (коэффициент вариации) для оценки стабильности.
- Медианный анализ интервалов + stability_ratio.
- Ожидание двух пропусков перед закрытием серии (CLOSE_AFTER_MISSES=2).
- GUI-фильтры отображения: мин.повторы, джиттер, CV%.
- Watchlist через GUI (watchlist.json, подсветка в таблицах).
- Арбитражные связки (MTLR/MTLRP), фандинг, новости MOEX.
- Telegram-бот для оповещений и меню.
