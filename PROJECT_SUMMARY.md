Приблуда на python — контекст проекта
Скринер роботов на MOEX. История: старт на Alor WebSocket + Tkinter;
с 2026-08-19 переезд на QUIK (lua → CSV → Python), GUI на PySide6;
с 2026-08-20 котировки дублируются с MOEX ISS (Quik не выдерживает
массовый getParamEx), все вкладки рабочие; с 2026-08-21 — два lua
(сделки + планки), tick-rule сторона, мс-точность, статистика и эталон.
Архитектура (актуальная)
QUIK export_trades.lua v3.10: лента сделок (tick-rule, мс).
QUIK limits_sweep.lua v5: планки (getParamEx с tonumber, ломтики 2/2 c).
tools/iss_quotes_sync.py: котировки TQBR из ISS.
CSV в data/ → connectors/quik/* (ридеры, backend v3 batch_flash) →
SharedState → GUI (PySide6, 7 вкладок включая Статистику).
Детектор: detectors/interval_robot.py v5 (first-fit; qty 2 варианта,
ratio 1.10; close_after_misses=6; история в момент подтверждения;
v6 — анти-шум в выдаче: LEN2 скрыты, длинные только LEN>=4).
Тесты 10/10.
Реализовано (2026-08-21)
Роботы: живой поиск, мини-окна, звуки, только рабочие серии, трей-эмодзи,
чипы планок и мигание тикера у планки, batch_flash (мигание пачки).
Планки из Quik: зоны, позиция дня, звук/мигание в момент входа,
гистерезис и кулдаун; limits_ui.json в корне (автоперенос).
Аукционы: эшелоны-колонки, расписание с отсчётом, статусы, мьют,
свои группы, "＋ Все (MOEX)" через ISS, "прочие события".
Арбитраж: absolute_rub/ratio_pct, EMA-база (half_life), "ПРОСТРЕЛ",
GUI-управление связками (arb_pairs.json), произвольные формулы спреда.
Фандинг (ISS SWAPRATE), Графики (цена/спред, matplotlib, ось справа).
Статистика: наш поток + эталон конкурента, импорт идемпотентный.
Служебное: make_dump v5 (берёт .lua и jsonl статистики), cleanup,
replay, robot_snapshot, диагностики, зонды.
Не сделано
Доведение поиска роботов до уровня конкурента (A/B по истории) и,
возможно, приведение вида главного окна к виду конкурента
(владелец привык) — следующая большая задача.
Точечные min_qty по тикерам с мелкими qty конкурента.
Трёхногие связки (symbol_c) — v2; свечи из Quik для графиков — v3;
индикативная цена аукциона из стакана; Telegram под absolute_rub.
SPBFUT не подключён в QUIK — фьючерсы в котировках отсутствуют.
Философия
Простой стек (без фреймворков/БД), JSON-настройки, только чтение рынка,
файлы целиком для владельца, "не гадаем — зонды", коммиты на русском,
наш поток = материал, конкурент = эталон.
