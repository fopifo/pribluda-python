Приблуда на python — контекст проекта
Скринер роботов на MOEX. История: старт на Alor WebSocket + Tkinter;
с 2026-08-19 переезд на QUIK (lua → CSV → Python), GUI на PySide6;
с 2026-08-20 котировки дублируются с MOEX ISS (Quik не выдерживает
массовый getParamEx), все вкладки рабочие; с 2026-08-21 — два lua
(сделки + планки), tick-rule сторона, мс-точность, статистика и эталон.
с 2026-09-05 — StreamGrid (стриминг-детектор сеток), aniscan.ru как
второй эталон, интеграция в backend.

Архитектура (актуальная)
QUIK export_trades.lua v3.10: лента сделок (tick-rule, мс).
QUIK limits_sweep.lua v5: планки (getParamEx с tonumber, ломтики 2/2 c).
tools/iss_quotes_sync.py: котировки TQBR из ISS.
CSV в data/ → connectors/quik/* (ридеры, backend v3 batch_flash) →
SharedState → GUI (PySide6, 7 вкладок включая Статистику).

Детекторы:
- detectors/interval_robot.py v12 — основной (адаптивный min_qty,
  фильтр двойных ударов, уточнение базы интервала вниз)
- modules/stream_grid.py v2.1 — стриминг-детектор сеток (ключ (sym, side),
  кластеризация объёмов, mr=6, tol=0.08). Интегрирован в backend,
  сигналы в shared.grid_signals.

Тесты 10/10 (робот) + 8 (volume_spike) + 7 (level_break) + 7 (spring) = 32.

Реализовано (2026-08-21)
Роботы: живой поиск, мини-окна, звуки, только рабочие серии, трей-эмодзи,
чипы планок и мигание тикера у планки, batch_flash (мигание пачки).
Планки из Quik: зоны, позиция дня, звук/мигание в момент входа,
гистерезис и кулдаун; limits_ui.json в корне (автоперенос).
Аукционы: эшелоны-колонки, расписание с отсчётом, статусы, мьют,
свои группы, "＋ Все (MOEX)" через ISS, "прочие события".
Арбитраж: absolute_rub/ratio_pct, EMA-база (half_life), "ПРОСТРЕЛ",
GUI-управление связками (arb_pairs.json), произвольные формулы спреда.
Фандинг (ISS SWAPRATE), Графики (цена/спред, matplotlib, ось справа).
Статистика: наш поток + эталон конкурента, импорт идемпотентный.
Служебное: make_dump v5 (берёт .lua и jsonl статистики), cleanup,
replay, robot_snapshot, диагностики, зонды.

Ревью и fixes (2026-08-22)
Баг №1: `eval()` в `load_ref` (ab_compare.py) молча терял записи
эталона с null-временем. Заменено на `json.loads()`. Эталон вырос
63 → 142 записей.
Баг №2: голые `datetime.now()` в `_write_history` и в GUI-часах —
заменены на `datetime.now(MSK)`. Убрано скрытое допущение.
Baseline A/B: TP=0 / FN=142 / FP=1270. TP=0 — не провал детектора,
а следствие tick-rule в QUIK (доказано через replay_sngsp.py).

Новые модули из LiveScreener (2026-08-23)
`modules/volume_spike.py` — всплески объёма за 1/2/3/4 секунды
(аналог индикатора VOLUME из LiveScreener). Скользящие окна,
анти-шум (threshold_multiplier + min_volume), кулдаун 10 сек.
`modules/level_break.py` — пробои уровней сопротивления/поддержки +
ранний подход заранее на N пунктов (аналог LEVELS). Гистерезис,
cooldown_sec, per-ticker настройка.
`modules/arbitrage/spring_monitor.py` — спред тикера относительно
индекса IMOEXF (аналог "пружины"). EMA-база, гистерезис,
отдельный поток загрузки IMOEXF.
Интеграция: `SharedState.spring_rows`, `backend.imoex_updater`,
отдельный `spring_settings.json` для конфигурации.

- Ключ буфера (sym, side) вместо (sym, side, qty) — чередующий робот
  (45/46) больше не распадается на две серии 2p

- Интеграция в backend: shared.grid_signals (живые сигналы за 60с)
- Логи: output/quik_noconsole.log (строки [stream_grid] SIGNAL)
- Отключение: USE_STREAM_GRID=False в core/config.py

Философия
Простой стек (без фреймворков/БД), JSON-настройки, только чтение рынка,
файлы целиком для владельца, "не гадаем — зонды", коммиты на русском,
наш поток = материал, конкурент = эталон, aniscan = второй эталон.
Гибрид: interval_robot остаётся ядром, параллельно работают новые
детекторы (volume_spike, level_break, spring_monitor, stream_grid).
