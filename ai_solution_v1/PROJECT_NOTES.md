# ПРАВИЛА И АРХИТЕКТУРА (читать каждому ИИ перед началом работы)

## 🔴 ЖЕЛЕЗНЫЕ ПРАВИЛА (нарушать нельзя)
1. **Только полные файлы.** Владелец занят торговлей, у него нет времени искать строки. Любая правка — это ПОЛНЫЙ код файла целиком (от первой до последней строчки). Никаких "найди строку 45 и замени".
2. **Правила только дополняются.** Если мы обновляем этот файл (PROJECT_NOTES.md), новые пункты ДОБАВЛЯЮТСЯ в конец. Старые правила НЕ УДАЛЯЮТСЯ и НЕ ПЕРЕПИСЫВАЮТСЯ, даже если кажутся устаревшими.
3. **Прогресс-бар обязателен.** Любой скрипт, работающий дольше 5 секунд, ОБЯЗАН иметь визуальный прогресс-бар.
   - Бар обновляется по времени (`time.perf_counter`) или по прочитанным байтам.
   - Обязательно использовать `sys.stdout.flush()` для мгновенного отображения.
4. **Оптимизация памяти.** Память не резиновая.
   - Файлы читать только построчно (`for line in f`). Никаких `readlines()` или `read()` целиком.
   - Для подсчета прогресса использовать `path.stat().st_size` (размер в байтах), а не двойное чтение файла.
   - Не хранить в памяти то, что можно не хранить (использовать генераторы и deque с фиксированной длиной).
5. **Безопасность.** Никакой торговли. Только чтение данных и запись логов.
6. **Экономия контекста.** Не читать логи, не создавать лишние файлы без спроса.

## 📂 Архитектура проекта
- `config.py` — все пороги и настройки детектора (min_interval_sec, min_qty и т.д.).
- `detect/interval.py` — ЯДРО. Детектор интервальных роботов (ищет сетки в ленте).
- `detect/registry.py` — реестр для управления несколькими тикерами.
- `orderbook.py` — детектор аномалий в стакане (мигалки/spoof и стены/wall).
- `combined.py` — СВЯЗКА. Берет сигналы из ленты и события из стакана, ищет совпадения по времени.
- `pipeline.py` — оркестратор для прогона ленты.
- `metrics.py` — сравнение с эталоном Aniscan (Precision/Recall).
- `cli.py` — командная строка.

## 📊 Форматы данных
- **Лента (`pbsdk_trades_*.jsonl`):** `{"symbol": "SBER", "side": "buy", "qty": 10, "price": 299.5, "timestamp": 1794984881837}`
- **Стакан (`orderbook_*.jsonl`):** `{"symbol": "SBER", "timestamp": 1794984881837, "best_bid": 299.4, "best_ask": 299.6, "bids": [[299.4, 100]], "asks": [[299.6, 150]]}`
- **Эталон Aniscan (`aniscan_robots_*.jsonl`):** период в СЕКУНДАХ, время в +04:00.

## ⚙️ Текущие проблемы и решения

- *Решение:* Переписан на обновление по времени с `sys.stdout.flush()`.

## 🔄 Правило 7. Рабочий цикл обмена файлами
1. **Владелец просит файл:** Владелец говорит, какой файл нужно изменить.
2. **Владелец присылает текущую версию:** Владелец открывает файл в блокноте, копирует и присылает его текущий код (чтобы ИИ видел реальное состояние, а не гадал).
3. **ИИ переписывает и проверяет:** ИИ вносит правки, проверяет синтаксис (py_compile, ast).
4. **ИИ отдает ЦЕЛЫЙ файл:** ИИ присылает полный, готовый код файла (с кнопкой копирования).
5. **Владелец вставляет и запускает:** Владелец копирует код, вставляет в блокнот, сохраняет и запускает в терминале.
6. **Владелец присылает хвост:** Владелец копирует вывод терминала (или ошибку) и присылает ИИ для проверки.
