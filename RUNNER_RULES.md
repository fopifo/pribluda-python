# RUNNER_RULES.md — правила ассистента-раннера (читать ПЕРЕД каждой задачей)

1. Рабочая зона — ТОЛЬКО C:\Users\Public\MI_CODES\Qwen_coder.
2. ЗАПРЕЩЕНО создавать файлы вне проекта (%TEMP%, профиль, др. диски).
3. Временные файлы — ТОЛЬКО output/, префикс tmp_, удалять сразу после использования.
4. ЗАПРЕЩЕНО изменять файлы, не указанные в задаче явно.
5. ЗАПРЕЩЕНО принимать решения (детектор, настройки, пороги) — это дело человека.
6. Команды выполнять дословно, вывод возвращать дословно, без сокращений.
7. Ошибка команды — вернуть дословно, НЕ «чинить» самостоятельно.
8. В конце — отчёт: создано/удалено/изменено (полные пути).
