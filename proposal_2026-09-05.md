## 3. Ключевой вывод — корень проблемы

**Онлайн-детектор «хоронит» серии.** База защёлкивается на редком ударе
(напр. 400с), одиночные 16с-удары «не влезают» в допуск, серия стоит и
умирает до подтверждения. Evict (MAX_ACTIVE_PER_SIDE) усугубляет: лавина
кандидатов при низком min_qty выносит слабые серии.

**Доказательство:** офлайн-метод «собирать и сортировать» (реконструкция
сетки по всем timestamps) ловит почти вдвое больше при том же входе.

## 5. Что хотим изменить (предложение)

### 5.1 [Приоритет 1] Стриминг-детектор в живой backend
Перенести класс StreamGrid в connectors/quik/backend.py. Сигнал на 4-м
ударе, задержка ~3×p. Код (ядро, из research/replay_grid.py):

```python
class StreamGrid:
    def __init__(self, min_repeats=4, buffer=60):
        self.buf = defaultdict(lambda: deque(maxlen=buffer))
        self.emitted = {}
        self.min_repeats = min_repeats

    def on_trade(self, sym, side, qty, ts):
        b = self.buf[(sym, side, qty)]
        b.append(ts)
        if len(b) < self.min_repeats:
            return None
        gaps = [(b[i+1]-b[i])/1000 for i in range(len(b)-1)]
        small = sorted(g for g in gaps if 1.0 <= g <= 120.0)
        if len(small) < 3:
            return None
        p = small[len(small)//2]
        if not (2.0 <= p <= 120.0):
            return None
        tail = gaps[-(self.min_repeats-1):]
        single = 0
        for g in tail:
            k = round(g/p)
            if k < 1 or abs(g - k*p) > max(k*p*0.12, 0.7):
                return None
            if k == 1:
                single += 1
        if single < 2:
            return None
        key = (sym, side, qty)
        last = self.emitted.get(key)
        if last is not None and ts - last < 4*p*1000:
            return None
        self.emitted[key] = ts
        return {"ticker": sym, "side": side, "qty": qty, "period": p, "ts": ts}

Интеграция (эскиз):
# connectors/quik/backend.py
self.grid = StreamGrid()                      # в __init__
sig = self.grid.on_trade(sym, side, qty, ts)  # в on_trade
if sig:
    self.state.grid_signals.append(sig)       # в GUI

Аддитивно: interval_robot не трогаем, StreamGrid — параллельный канал.
