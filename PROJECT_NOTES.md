## Наблюдения по детектору
- Наш поток шумнее эталона: длинные серии 100-600 c с LEN 2-3 —
  ложные (конкурент их не показывает). Короткие роботы конкурента
  (10-60 c) мы часто пропускаем из-за min_qty=50 (у конкурента qty
  10-50) и допуска 5%.
- Волны конкурента: ~10:30 / 11:03 / 11:28 (пачка 10-20 тикеров,
  интервалы 12-18 c, LEN растёт до 138).
- Валюта/фьючерсы (CNY_TOM, Si-9, ED-9) конкурент видит — мы по
  дизайну только TQBR (SPBFUT не подключён в Quik).
- По скриншотам конкурента видно по несколько роботов на один тикер
  (LKOH — до 6, MIX-9 — до 5, SI-9 — до 4). Также "синхронная волна"
  ~14 роботов разных тикеров бьют в один NEXT (алгоритм-пачечник).

## Правило PowerShell для сессий
- Длинные here-string в PSReadLine падают с `System.ArgumentOutOfRange
  Exception: Значение должно быть больше или равно нулю и меньше,
  чем размер буфера` — баг PSReadLine, не пользователя.
- Файлы создавать через `python -c "..."` одной командой, либо
  разбивать длинные here-string на короткие pipe-команды.
- При `@"..."@ | Set-Content` строго следить: `"@` — в самом начале
  своей строки.
