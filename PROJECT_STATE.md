# ПРОЕКТ dpNEW — СОСТОЯНИЕ. ЧИТАТЬ ПЕРВЫМ ДЕЛОМ В НОВОЙ СЕССИИ.
Обновлено: 2026-11-25 утро, после запуска v5.

## Как пользоваться
Пользователь прикрепляет этот файл первым сообщением новой сессии. Алиса читает его И RULES.md (рядом) и продолжает работу без пересказа с нуля. В конце сессии пользователь говорит «обнови STATE.md» — Алиса выдаёт обновлённый текст, файл перезаписывается ЦЕЛИКОМ.

## Правила работы
ВСЕ правила — в RULES.md рядом с этим файлом. Он защищён: только дополнение в конец с датой, read-only атрибут, каждый чендж — коммит. Переписывать и удалять существующие правила нельзя.

## Архитектура
- Мост (сторонний): пишет ленту сделок data/pbsdk_trades_YYYY-MM-DD.jsonl
- tools/entities_aggregator.py (v5): серии из принтов. Пороги: MIN_N=8, STARTUP_S=5, MAX_GAP_S=90. Адаптивный допуск цены: базовый 0.05%, растёт с возрастом серии (удвоение за 5 мин), потолок 0.5%. Отсечка блоков: серия выбрасывается целиком, если её объём > BLOCK_SHARE (0.70) дневного оборота тикера (оборот копится по всем сделкам дня). Пишет data/entities_YYYY-MM-DD.jsonl и data/entities_live.json (снапшот, раз в секунду).
- tools/entities_replay.py: офлайн-прогон ленты дня (импортирует Aggregator из entities_aggregator — правки одного файла проверяются реплеем). Запуск: py entities_replay.py YYYY-MM-DD. Пишет data/replay_entities_*.jsonl. Фильтр блоков встроен в его finalize.
- tools/overlay.py (v2.8): полоски поверх пульта, читает entities_live.json. Пульт: F9, двойной клик по ячейке. Пустой/битый entities_live.json переживает корректно (проверено 25.11).
- tools/web_panel.py: панель, читает entities_live.json.
- TW-лог: data/tw_robots_YYYY-MM-DD.jsonl — данные стороннего скринера.
