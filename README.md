# Приблуда на python

Скринер, который ищет признаки алгоритмической торговли в ленте сделок
Московской биржи через API брокера Алор: сделки одинаковым объёмом лотов
через одинаковый интервал времени, а в перспективе — более сложные паттерны.

## Статус проекта

**Фаза 1 (текущая):** проверка подключения к Алор — получение access-токена
(JWT) по refresh-токену. Пока ничего не торгуем и не анализируем, просто
убеждаемся, что связь с брокером есть.

## Установка

1. Установи Python 3.10+, если ещё не установлен.
2. Открой эту папку в VSCode.
3. Создай и активируй виртуальное окружение:
   - Windows (PowerShell): `python -m venv venv` затем `venv\Scripts\Activate.ps1`
   - Mac/Linux: `python3 -m venv venv` затем `source venv/bin/activate`
4. Установи зависимости:
   ```
   pip install -r requirements.txt
   ```
5. Скопируй файл `.env.example` и переименуй копию в `.env`.
6. Открой `.env` и вставь туда свой refresh-токен от Алора вместо заглушки.
7. Запусти:
   ```
   python main.py
   ```

## Что должно произойти

В консоли должно появиться `Подключение успешно!` и длина полученного
access-токена — значит refresh-токен рабочий и связь с Алором есть.

Если появилась ошибка — скопируй её текст целиком и пришли мне, разберём.

## Важно про безопасность

- Файл `.env` никогда никуда не отправляй и не публикуй (он в `.gitignore`,
  так что в git точно не попадёт).
- Если когда-либо случайно показал свой настоящий refresh-токен в чате,
  скриншоте или репозитории — считай его скомпрометированным и перевыпусти
  в личном кабинете Алора.
