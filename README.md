# Приблуда на Python

Скринер торговых роботов (алгоритмов) на Московской бирже (MOEX) по ленте сделок через API брокера Алор.

## Возможности

- Поиск алгоритмических серий:
  - **fast_strict** — классический робот: одинаковый объём, стабильный интервал (3–30 сек).
  - **twap_strict** — TWAP-робот: объём не важен, главное — точный тайминг (интервал 3–60 сек).
- Живой режим (WebSocket) с переподключением и watchlog’ом.
- Исторический прогон по данным из `data/` (несколько дней).
- GUI на Tkinter с вкладками:
  - Роботы (с фильтрами отображения по повторам, джиттеру, CV%)
  - Арбитраж
  - Фандинг
  - Новости MOEX
- Watchlist: управление приоритетными тикерами через GUI (подсветка в таблицах).
- Логирование в `output/`, аналитика в `tools/analyze.py`.
- Telegram-бот для уведомлений (арбитраж, меню).

## Запуск

1. Установите зависимости: pip install -r requirements.txt

2. Создайте файл `.env` в корне проекта со строками: ALOR_REFRESH_TOKEN=ваш_токен, TELEGRAM_BOT_TOKEN=токен_бота, TELEGRAM_CHAT_ID=id_чата, TELEGRAM_ENABLED=True

3. Запуск живой сессии: python start_all.py или python live_screener.py

4. Исторический прогон: python run_detectors.py --all-days

5. Анализ отчётов: python tools/analyze.py (по умолчанию агрегированный отчёт с топ-паттернами и кратными интервалами)

## Структура проекта

- detectors/ — детекторы роботов.
- gui/ — графический интерфейс.
- dashboard/ — сбор строк для отображения.
- arbitrage/ — арбитражные связки.
- tg_bot/ — Telegram-бот и интеграции.
- tools/ — анализаторы и утилиты.
- data/ — исторические данные (не в Git).
- output/ — логи и отчёты (не в Git).
