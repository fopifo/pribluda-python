# Приблуда на python

Скринер торговых роботов (алгоритмов) на Московской бирже (MOEX) — для
трейдера-скальпера. Ищет серии сделок с устойчивым интервалом времени
(признак автоматической торговли), плюс отдельно следит за
арбитражными связками инструментов (например, обычка/префа) и
показывает всё это в живом GUI-окне, с уведомлениями в Telegram.

## Что делает

- **Поиск роботов** — находит серии сделок одного тикера и стороны
  (buy/sell), повторяющиеся с устойчивым интервалом. Два режима:
  - `fast_strict` — объём лота одинаковый каждый раз, интервал 3-30
    сек, минимум 3 повтора подряд
  - `twap_strict` — объём МОЖЕТ отличаться каждый раз (ловит крупные
    заявки, нарезанные по времени на равные интервалы), но требует
    более строгую точность интервала (5% вместо 10%)
  - Для каждой найденной серии считается **джиттер** — насколько ровно
    держится интервал (в миллисекундах) — чем ниже, тем больше похоже
    на чистый программный автомат, а не на совпадение/имитацию человеком
- **Арбитраж** — следит за отношением или абсолютной разницей цен пары
  инструментов, сигнализирует о "прострелах" (расхождение) и
  "схождениях" (когда пора закрывать позицию)
- **Фандинг** — ставки по фьючерсам FORTS (MOEX ISS)
- **Новости** — лента с сайта MOEX
- Всё это — в GUI-окне (вкладки: Роботы / Арбитраж / Фандинг /
  Новости) и частично дублируется в Telegram (арбитраж — да, роботы —
  нет, см. ниже почему)

## Почему роботов нет в Telegram

Сигнал по роботу приходит только когда серия УЖЕ ЗАКРЫЛАСЬ — то есть с
задержкой, часто когда робот уже неактивен. Для скальпинга это
бесполезно, поэтому наблюдение за роботами — только через GUI (в
реальном времени, пока серия ещё активна). Арбитраж — другое дело, там
расхождение сохраняется в моменте, задержка не так критична.

## Установка и запуск

Установить зависимости:

```
pip install -r requirements.txt --break-system-packages
```

`.env` в корне проекта должен содержать:

```
ALOR_REFRESH_TOKEN=...
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
TELEGRAM_ENABLED=true
```

Запуск (единая точка входа — GUI + бэкенд + Telegram-меню одним процессом):

```
python start_all.py
```

или через ярлык `start_gui.bat` (запускает без консоли, для рабочего дня).

## Структура проекта

```
detectors/       — ядро: поиск серий (IntervalRobotDetector)
arbitrage/        — монитор арбитражных связок (PairMonitor)
gui/               — окно (Tkinter): главное + компактное поверх терминала
tg_bot/            — Telegram: push-уведомления + интерактивное меню
dashboard/         — превращает состояние детекторов в строки для GUI
analysis/          — офлайн-анализ: прогон по истории, поиск TWAP-паттернов,
                     еженедельные сжатые отчёты
tools/             — разовые инструменты (диагностика API, дамп проекта)
tests/             — модульные тесты детектора
config.py          — какие пресеты включены, пороги по умолчанию
ticker_settings.json — список тикеров, ручные пороги (правится через GUI)
arb_pairs.json     — арбитражные связки и их пороги
```

## Настройка тикеров

Через кнопку "⚙ Настройки тикеров" в GUI — включение/выключение
тикеров, ручные пороги (мин. лотов/сек/повторов) на каждый отдельно.
Применяется на лету, без перезапуска.
